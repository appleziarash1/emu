# VEILBORN
2D Action Roguelike / Hack-and-Slash / Narrative Adventure.
Hero: Cael Varen. Hub: The Shattered Gate.
Realms: Ash, Tides, Frost, Shadows, Forgotten Throne.
Bosses: Zyther, Seraphine, Auren, Draemor, The Hollow.
Weapons: Ashen Edge, Pyre Lance, Tempest Gauntlets, Moonthread Bow, Gravewind Scythe, Tidebreaker Chakrams.
Core loop: Hub -> procedural rooms -> combat -> reward/boon -> elite -> boss -> story progression -> next realm.
Endings: Sealed Veil, Open Veil, New Veil, True Ending: The Veilborn.
